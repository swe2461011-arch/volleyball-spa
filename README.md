# VolleyShop

Волейболын пүүз, бөмбөг, өмсгөл, hoodie, халаалтын цамц/өмд, хамгаалалт, цүнх зэргийг танилцуулах **SPA** вэбсайт.

> Номын 2.10–2.13-ын жишээг өөр сэдвээр (волейболын хэрэгсэл) бүрэн өөрчилж хийсэн төсөл.

## Хуудсууд

| Route | Тайлбар |
|-------|---------|
| `#/overview` | Нүүр |
| `#/search` | Бүтээгдэхүүн хайлт |
| `#/budget` | Төсөв тооцоолуур |
| `#/guides` | Зөвлөгөө |
| `#/contact` | Холбоо барих |

## Локал ажиллуулах

```bash
cd docs
python3 -m http.server 8080
```

Browser: http://localhost:8080

## GitHub Pages

1. Repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` · Folder: **/docs**
4. Save → хэдэн минутын дараа сайт нээгдэнэ:
   `https://<username>.github.io/volleyshop/`
